금주는 이리저리 외부 활동이 많았는데, 갑자기 날씨가 추워 지더니 잘 걸리지 않는 목감기가 찾아왔다.
그냥 몸살은 사실 쉽게 지나가는데, 목이 아픈건 어렸을 때 부터 지금까지 그냥 지나간 적이 없다. 결국은 병원을 가게 되는데, 이럴거면 그냥 목 좀 칼칼하다 싶으면 재빠르게 병원을 가는게 좋은 것 같다.

머리도 아프고 코막힘에 기침이 지속되니, 따로 뭔가를 진행해보려 해도 집중이 안된다. 누워있는 시간이 많아지고, 아무것도 하기 싫어지는 날이다.
몸이 아픈건 쉬라고 하는 신호니깐 마음 편하게 쉬고 싶은데, 지금 나는 그럴 상황은 아닌 것 같다.

예전과 달리 AI가 작업을 대신할 수 있어서, 이렇게 몸이 아픈 날은 조금 더 가벼운 작업을 가벼운 마음으로 냅다 지시해버린다. 생각하는것도 지쳐서 '헤줘' 를 연발하고 있다.
적어도 지금 시점에서, AI에게 작업을 완전히 위임해도 어느정도의 퀄리티가 보장되니 참 신기한 세상이다. 개인적인 느낌으로는 25년만 해도 이정도는 아니었던 것 같은데, 얼마 지나지도 않았지만 어느 새 여기까지 도달했다.

25년 초중반쯔음에 cursor 에서 코파일럿 외 직접 agent 가 mcp 를 연결해서 자연어 지시에 맞게 작업을 진행해주는 것을 보고 놀라워 하면서도, 아직까지는 뭐 큰 작업을 맡기기에는 부족한 퀄리티를 보여주는 것 같아서 마음을 좀 놓고 있었는데,
이번에 좀 맘 놓고 바이브 코딩을 진행하다 보니, 조금 방향만 잡고 있으면 금새 사람들이 쓸 만한 퀄리티로 프로토타입을 만드니 기분이 묘하다. 이런 시대다 보니 하루라도 더 나의 지식 범위를 넓혀서 더 확실한 지시와 검토를 할 수 있지 않으면 개발자를 이어갈 수 없지 않을까 무서워 진다.
아프지만 쉽게 쉬지 못하는 날이다.

> AI가 대부분의 작업을 해주지만, 그럼에도 쉽게 쉬지 못하는 날이다.

그런데 계속 지시만 한다 생각했는데, 최근 codex 나 claude 의 작업 방향을 보면 오히려 나는 '대답' 만 하고 있다는 생각이 든다. 그리고 이게 실제로 그러한 경우가 많아지고 있다.
codex app 에서 작업을 하는데, 답변에 더해 어떠한 '지시' 를 내릴지 미리 자동 완성을 시켜준다. 마침 오늘은 머리가 아파 생각하기 힘들어서 하고싶은데로 해봐란 느낌으로 탭을 열심히 눌러주었는데, 어느 순간 내 주도권을 잃어버리고, 뭘 진행하고 있는지 모르겠지만 대답을 하고 있는 나를 발견했다.
구현은 계속 되고 있지만 도대체 뭘 하고 있는건지 알 수 없는 상태가 되었다. 이 떄 만약에 작업하는 프로젝트가 실제 회사나 사업의 production 이었다면 무섭게도 한 순간에 맥락을 잃어버리게 되는 상황을 맞이하게 될 지도 모르겠다는 생각이 들었다. 그리고 이렇게 잃어버린 맥락을 다시 AI에게 물어봐서 찾아오고, 이를 반복하고,
토큰 사용량만 늘어나면서, 내 불안감은 계속 지속될 것 같았다.

너무 편리해진 세상이지만, 봐야할 많은 코드들이 생겨나고, 확인해야할 사항들이 많아지면 인간은 반드시 지칠것이다. 몸살난 나처럼.
생각을 하는것에 너무 지치게 되는 상황이 지속된다면, 이것 역시 감기처럼 휴식이 필요한 것이 아닐까.
